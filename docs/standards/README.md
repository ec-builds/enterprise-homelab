# Standards

Standards used to maintain consistency across the enterprise homelab and its documentation.

| Standard | Description |
|---|---|
| [Administrative Access Standard](./admin-access-standard.md) | Administrative accounts, privileged access, authentication, and credential handling |
| [Documentation Standards](./documentation-standards.md) | Documentation structure, formatting, status, and repository conventions |
| [Linux Server Standard](./linux-server-standard.md) | Baseline configuration and validation requirements for Linux servers |
| [Naming Conventions & Sanitization](./naming-conventions.md) | Public naming and sanitization requirements |
| [Virtual Machine Deployment Standard](./vm-deployment-standard.md) | Baseline deployment, configuration, and validation requirements for virtual machines |
