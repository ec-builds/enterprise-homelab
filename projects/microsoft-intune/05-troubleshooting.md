**Status: ⚪ Planned**

Case studies built from deliberately broken scenarios, each documented as an investigation rather than a set of configuration steps.

## Case Study Format

Each case study follows the same structure:

| Section | Content |
|---|---|
| **Symptom** | What the user or administrator observed |
| **Evidence** | Logs, reports, and device-side diagnostics collected |
| **Root cause** | What actually went wrong |
| **Resolution** | The fix and how it was verified |
| **Prevention** | What would stop it recurring |
